Produce an asset set from this brief: $ARGUMENTS

Delegate this to the `magnific-art-director` subagent — multi-asset work needs
the shot list, the shared reference, and the one-at-a-time review loop it runs.

Before delegating, make sure the brief actually answers:

- What the assets are for (campaign, thumbnails, storyboard, product page)
- How many, and at what aspect ratio(s)
- What must stay consistent across them — a character, a product, a palette, a
  lighting setup
- Whether anything must stay faithful to a real source (a real product or person)
  or is free to be invented

Ask about any of those that are missing. An underspecified brief is what turns
into a set that has to be regenerated.

If the brief is a file path, read it first.
